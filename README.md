# TolSMP — справочник CoreProtect

Сайт: https://magomedovex-code.github.io/tolsmp/

Справочник для админа сервера TolSMP (Minecraft 1.21.11). Всё сверено с исходным кодом CoreProtect 24.1.

- **Главное за 1 минуту** — #preview только для блоков, откат инвентаря (игрок онлайн + u:), координаты через a:-item, радиус, дюп
- **Игрок умер** — координаты смерти, кто убил, кто подобрал, вернуть вещи
- **Ситуации** — уничтожил ли убийца вещи, ПвП, гриф, воровство/шалкеры, взрыв, лава, X-ray, чат, мобы, откатил лишнее, тюрьма 1
- **Как читать ответ** и **Ошибки** — точные сообщения плагина и что делать
- **Конструктор** — собирает команду и проверяет её по правилам плагина
- **Все команды** (с поиском), **Параметры**, **Законы**, **Права и config.yml**

Старые версии: `archive/moder.html`, `archive/admin.html`.
