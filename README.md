# TolSMP — шпаргалка модератора

Сайт для модераторов Minecraft-сервера TolSMP (1.21.11):

- **Книга** — все 11 страниц книги «CoreProtect — команды для модераторов» с перелистыванием
- **Симулятор** — анимации всех команд CoreProtect и Essentials (mute, jail, kick, ban, gm 3, tp…)
- **Фильтр a:** — как работает фильтр действий в `/co lookup`
- **Законы и наказания** — все законы сервера с готовыми командами проверки и наказания
- **Конструктор** — собирает команду поиска или наказания
- **Все команды** — кто что может (Moder / Админ / Консоль)

Открыть: https://magomedovex-code.github.io/tolsmp/
